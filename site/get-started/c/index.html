Download the native library

Choose the archive for your platform from the matching GitHub release. It contains the public header, shared and static libraries, relocatable CMake metadata, the ABI contract, and checksums. Unix archives also contain pkg-config metadata.

find_package(Ironpages CONFIG REQUIRED)
target_link_libraries(your_target PRIVATE Ironpages::C)

Point CMAKE_PREFIX_PATH at the extracted archive. Use Ironpages::CStatic for static linkage. Unix pkg-config consumers can resolve ironpages for shared linkage or ironpages-static for static linkage.

Create an HTML PDF

#include "ironpages.h"

#include <stdint.h>
#include <stdio.h>
#include <string.h>

int main(void) {
    const char *source = "<h1>Hello from C</h1>";
    IronpagesBytes html = {(const uint8_t *)source, strlen(source)};
    IronpagesBuffer *pdf = NULL;
    IronpagesError *error = NULL;

    if (ironpages_html_to_pdf(html, &pdf, &error) != IRONPAGES_STATUS_OK) {
        fwrite(ironpages_error_message_data(error), 1,
               ironpages_error_message_len(error), stderr);
        ironpages_error_free(&error);
        return 1;
    }

    FILE *file = fopen("output.pdf", "wb");
    if (file == NULL) {
        ironpages_buffer_free(&pdf);
        return 1;
    }
    fwrite(ironpages_buffer_data(pdf), 1, ironpages_buffer_len(pdf), file);
    fclose(file);
    ironpages_buffer_free(&pdf);
    return 0;
}
Ownership rule

Initialize every output handle to null. Free it through its matching function, which also clears the handle.

Render Markdown

Markdown uses the same owned buffer and error contract:

const char *source = "# Release notes\n\nEverything shipped.";
IronpagesBytes markdown = {(const uint8_t *)source, strlen(source)};
IronpagesStatus status = ironpages_markdown_to_pdf(
    markdown, &pdf, &error
);

Reuse a configured converter

Create one converter, configure it while idle, and reuse it for multiple documents.

IronpagesConverter *converter = NULL;
ironpages_converter_new(&converter, &error);
ironpages_converter_set_page_size(
    converter, IRONPAGES_PAGE_SIZE_LETTER, &error
);
ironpages_converter_set_margin(converter, 36.0f, &error);
ironpages_converter_set_compress(converter, IRONPAGES_TRUE, &error);

ironpages_converter_convert_html(converter, html, &pdf, &error);
ironpages_buffer_free(&pdf);
ironpages_converter_free(&converter);

Provide fonts as bytes

The C ABI does not read document paths or access the network. Your application may read a TrueType font or optional CJK or emoji pack, then pass its bytes to the converter.

Input ranges are borrowed only for the duration of the call. The converter copies custom fonts and takes its own parsed font-pack value.

Handle failures and runtime limits

Every fallible function returns a stable status. An optional owned error adds a UTF-8 diagnostic. Rust panics are contained before they reach C.

  • HTML sanitization is enabled by default.
  • Converters must not be used or freed concurrently.
  • Local paths, direct file output, async, streaming, and remote HTTP are absent.
  • Check ironpages_abi_version() before depending on a new ABI generation.
